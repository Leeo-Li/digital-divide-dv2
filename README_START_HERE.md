# Digital Divide Starter Project

This is a starter folder for the FIT2179 Data Visualisation 2 project:

**Topic:** Who Is Left Behind in Australia's Digital Life?  
**Story:** Australia is digital, but digital inclusion is unequal across dimensions, locations and people.

## File structure

- `index.html` — one scrollable webpage layout
- `style.css` — page styling
- `vega_lite_vis.js` — embeds all Vega-Lite charts
- `data/` — small CSV and GeoJSON files
- `vis/` — Vega-Lite `.vg.json` specifications

## Important TODO

`data/adii_state.csv` is a template. I did **not** fill state ADII scores because the uploaded `Total.xlsx` does not contain State/Territory scores.

Fill it from the ADII dashboard:

1. Year: 2024
2. View by: States and Territories
3. Metric: ADII Score
4. Export data
5. Copy the score values into `data/adii_state.csv`

The map file `data/australia_states.geojson` was generated by dissolving and simplifying your uploaded `a2_map.geojson` into State/Territory boundaries. If your tutor requires the official STE boundary layer, replace it with a GeoJSON exported from `STE_2021_AUST_GDA2020` and keep the property name `STATE_NAME_2021`, or update the lookup field in `vis/03_state_choropleth_map.vg.json`.

## Visualisations included

1. Dimension bar chart
2. Access and Digital Ability trend line chart
3. State/Territory choropleth map
4. State/Territory ranking bar chart
5. Metro vs Regional dumbbell chart
6. Age group bar chart
7. Income lollipop chart
8. Education level bar chart
9. Social groups dot plot
10. Most at-risk groups ranking chart

KPI cards can be added in HTML and do not need to count toward the 10 visualisations.
